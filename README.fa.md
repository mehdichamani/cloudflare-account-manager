# سامانه مدیریت اکانت‌های کلودفلر (Cloudflare Account Manager)

یک داشبورد مدرن، زیبا و با قابلیت تغییر تم (روشن/تاریک) همراه با ابزار خط فرمان (CLI) جهت مدیریت و مانیتورینگ روزانه میزان استفاده، ورکرها، پروژه‌های Pages، دامنه‌های متصل و تاریخچه دیپلوی در چندین اکانت کلودفلر. ساخته‌شده به‌طور کامل به عنوان Cloudflare Worker با استفاده از Cloudflare KV.

## ✨ امکانات و قابلیت‌ها

- 📊 **مانیتورینگ یکپارچه مصرف و سهمیه:** پایش درخواست‌های روزانه ورکرها با نوار زمان پیشرفت ریست روزانه بر اساس ساعت گرینویچ (UTC).
- ⚡ **فهرست جامع ورکرها و پروژه‌ها:** نمایش تمامی Workerها و پروژه‌های Pages فعال در هر اکانت.
- 🕒 **تاریخ دیپلوی و دامنه‌های متصل:** نمایش تاریخ آخرین تغییر یا دیپلوی و دامنه‌های سفارشی متصل به هر سرویس.
- 🔗 **ثبت لینک گیت‌هاب و توضیحات برای هر ورکر:** امکان پیوست کردن آدرس مخزن گیت‌هاب و توضیحات دلخواه برای هر ورکر از طریق داشبورد یا API.
- 💻 **پشتیبانی از CLI و API کش‌شده:** جستجو و دریافت اطلاعات ورکرها از طریق ترمینال و اسکریپت `cf-cli.sh` (مثلاً یافتن اینکه یک پروژه روی کدام ورکرها قرار دارد).

## 💻 راهنمای استفاده از CLI و API

یک اسکریپت سبک برای خط فرمان (`cf-cli.sh`) در مخزن قرار گرفته است تا بتوانید به سرعت از دیتای کش‌شده در ترمینال استفاده کنید:

```bash
# تنظیم آدرس دیپلوی ورکر (یا پیش‌فرض localhost:8787)
export CF_MANAGER_URL="https://your-manager.workers.dev"

# مشاهده آمار مصرف تمامی اکانت‌ها
./cf-cli.sh accounts

# دریافت ورکرها و پیج‌های همه اکانت‌ها یا یک اکانت مشخص
./cf-cli.sh resources [account_id]

# مشاهده فقط ورکرهای یک اکانت خاص
./cf-cli.sh workers <account_id>

# جستجوی معکوس پروژه (پیدا کردن اکانت و ورکرهایی که فلان پروژه روشون دیپلوی شده)
./cf-cli.sh find anti-filter
```

### اندپوینت‌های مستقیم JSON:
- `GET /api/v1/accounts`: دریافت لیست کلی اکانت‌ها و مصرف.
- `GET /api/v1/resources?account_id=...`: دریافت ورکرها و پیج‌ها همراه با متادیتا و تاریخ دیپلوی.
- `GET /api/v1/lookup?project=...`: جستجوی معکوس بر اساس نام پروژه یا لینک گیت‌هاب.
- `POST /api/worker-meta`: ذخیره یا تغییر لینک گیت‌هاب و یادداشت ورکر (نیازمند توکن ادمین).
- `POST /api/pages-meta`: ذخیره یا تغییر لینک گیت‌هاب و یادداشت پروژه Pages (نیازمند توکن ادمین).
